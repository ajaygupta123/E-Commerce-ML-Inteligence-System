# Jupyter Notebooks

This directory contains exploratory notebooks for data analysis and model development.

## Notebooks

1. **01_eda.ipynb**: Exploratory Data Analysis
   - Dataset overview
   - Data quality checks
   - Feature distributions
   - Missing value analysis

2. **02_feature_engineering.ipynb**: Feature Engineering
   - Feature transformations
   - Categorical encoding strategies
   - Feature selection

3. **03_model_comparison.ipynb**: Model Comparison
   - LightGBM vs CatBoost comparison
   - Performance metrics
   - Training time analysis

4. **04_shap_analysis.ipynb**: SHAP Analysis
   - Feature importance
   - SHAP value distributions
   - Explanation examples

## Setup

To run these notebooks:

```bash
# Install Jupyter
pip install jupyter

# Start Jupyter
jupyter notebook

# Or use JupyterLab
jupyter lab
```
